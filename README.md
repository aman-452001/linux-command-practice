# Linux Command Practice & Documentation

## About This Project

This repository documents my learning journey in Linux command-line fundamentals as part of my cybersecurity studies.

The goal is to understand essential Linux commands, practise them in a Linux environment, and document their behaviour with examples and observations.

## Topics Covered

- Navigating directories: `pwd`, `cd`, `cd ..`
- Listing files: `ls`, `ls -l`, `ls -a`, `ls -la`
- Understanding absolute and relative paths
- Exploring file and directory permissions
- Recording command outputs and troubleshooting observations

## Practice Environment

My practice environment may include Kali Linux or Ubuntu, depending on the lab exercise.

## Learning Method

For each topic, I aim to document:

1. The purpose of the command
2. Its syntax
3. A practical example
4. The observed output
5. Common mistakes and lessons learned

## Ethical Practice

All exercises are performed in environments I own or am authorised to use.

## Progress

This project is being developed as I learn Linux and cybersecurity fundamentals.
